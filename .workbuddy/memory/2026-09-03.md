## Git 凭据弹窗排障（已根治，经验可复用）
- 现象：每次 push 弹 Git for Windows "Credential Helper Selector"（选 manager + 勾 Always use 仍无效），push 命令挂起至 SIGTERM。
- 根因（铁证）：PortableGit 系统级 `etc/gitconfig` 里 `credential.helper=helper-selector` 与用户级 `~/.gitconfig` 的 `git-credential-manager.exe` 并存；git 先调用系统级 helper-selector，弹窗每次必现，"Always use"写入用户级 selected 键但系统级选择器不理会。
- 修复（Git 邮件列表官方做法）：用户级 `git config --global --unset-all credential.helper`，再 `--add credential.helper ""`（空值重置、屏蔽低优先级 system helper），再 `--add credential.helper '!"<GCM绝对路径>"'`；并 `--unset credential.helperselector.selected`。
- 验证：修复后 `git credential fill` 静默返回缓存凭据；真实 push（ee28c35）秒级完成无弹窗。
- 教训：先上网查证再动手（该弹窗是 Git for Windows 已知问题，搜索即有官方解）；同类问题先跑 `git config --list --show-origin | grep credential` 看各层配置打架。
