Agent Skill 速成

读图约 40 秒 · 自适应测验 2–7 题
Core Fact · 先纠一个普遍误解

Skill 不是「一个文件」，
而是一个文件夹（目录）

把一套技能经验装进一个目录：目录名即技能名，里面必有一个 SKILL.md 当"总指挥"。

本质一个文件夹 核心SKILL.md 装入.workbuddy/skills/
01

Skill 目录长什么样

pdf-helper/ ← 目录名 = 技能名 ├── SKILL.md 必需 │ ├── frontmatter：name · description │ └── 正文：分步操作指令 ├── scripts/ 可选 │ └── rotate.py ├── references/ 可选 │ └── spec.md └── assets/ 可选 └── logo.png
必需：只有 1 个文件

SKILL.md —— 头部 YAML 元信息 + 正文步骤，AI 的"操作手册"。

可选：3 个配套目录

scripts/ 脚本 · references/ 参考资料 · assets/ 模板素材，按需添加。

SKILL.md 的头部元信息

name 技能名 · description 带触发词的介绍 —— 决定 AI 何时认出并调用。

02

技能目录放进哪里

用户级
~/.workbuddy/skills/<技能名>/

所有项目通用 —— 个人技能放这里。

项目级
<项目>/.workbuddy/skills/<技能名>/

跟随仓库，协作者共享 —— 团队约定放这里。

两条原则

装第三方：先审计

从网络下载的技能包可能夹带风险脚本，安装前分级把关：

P0 危险，别装 P1 谨慎确认 P2 安全可装

自己的技能：三字诀

完成后 积累 —— 沉淀成技能目录
用完后 反思 —— 找改进空间
发现错 修正 —— 当场改不拖延
